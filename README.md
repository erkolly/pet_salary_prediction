# Прогноз зарплаты в Data Science / ML

Модель предсказывает годовую зарплату специалиста по данным (в $) по опыту, должности, стране, размеру компании и формату работы. К ней есть веб-приложение на Streamlit.

**Датасет:** [Data Science Job Salaries](https://www.kaggle.com/datasets/ruchi798/data-science-job-salaries) (Kaggle): 607 анкет за 2020–2022 гг., после удаления дублей 565.

## Результат

| Метрика (отложенный тест, 20%) | Значение |
|---|---|
| Средняя ошибка (MAE) | ≈ $29 000 |
| Медианная ошибка | ≈ $20 000 |
| R² (на логарифме зарплаты) | 0,67 |
| Прогнозов с ошибкой не больше ±30% | 65% |
| Бейзлайн «всем медиану», MAE | ≈ $53 000 |

Сравнивал Ridge, Random Forest и Gradient Boosting повторной кросс-валидацией (5 × 3). Все три почти равны, разница меньше разброса между фолдами. **Выбрана Ridge-регрессия**: она проще и устойчивее, а её коэффициенты читаются напрямую.

## Что выяснилось

| Фактор (при прочих равных) | Эффект на зарплату |
|---|---|
| Живёт в США (против Индии, Африки и т.п.) | ×3 |
| Живёт в богатой стране: Канада, Зап. Европа, UK, Япония… | ×2 |
| +1 уровень опыта (Junior → Middle → Senior → Executive) | +27% за ступень |
| Лидерская роль (Lead / Head / Director / Principal) | +32% |
| ML/AI-инженер против аналитика | +43% |
| +1 ступень размера компании | +12% |
| Доля удалёнки | почти не влияет |

Главная находка: **страна влияет на зарплату не слабее опыта**. Гипотеза из EDA «должности лучше сгруппировать по смыслу» подтвердилась: 20 признаков вместо 170 дают то же или лучшее качество.

## Структура

```
data/ds_salaries.csv        датасет
notebooks/01_eda.ipynb      разведочный анализ
notebooks/02_modeling.ipynb признаки, сравнение моделей, интерпретация, ошибки
```

## Запуск

```bash
python -m venv venv
venv\Scripts\activate            # Windows   (Linux/Mac: source venv/bin/activate)
pip install -r requirements.txt

python src/train.py              # обучить модель (≈15 секунд)
streamlit run app.py             # открыть приложение в браузере
```

Если пропустить `train.py`, приложение обучит модель само при первом запуске.

## Признаки

| Сырая колонка | Признак | Почему |
|---|---|---|
| `experience_level` | 0…3 | Порядок важен: EN < MI < SE < EX |
| `job_title` (50 названий) | 5 семейств + флаг «лидерская роль» | Половина названий встречается 1–3 раза |
| `employee_residence`, `company_location` (59 стран) | 4 региона по уровню зарплат + «живёт в стране компании» | В большинстве стран меньше 5 записей |
| `company_size` | 0…2 | |
| `employment_type` | полная занятость да/нет | 97% — full-time |
| `salary`, `salary_currency` | **удалены** | Утечка таргета: это та же зарплата в другой валюте |

Таргет — `log(salary_in_usd)`: у зарплат длинный хвост, а факторы действуют «в разах».

## Ограничения

- Данные за 2020–2022, больше половины анкет из США.
- По России, СНГ, Азии и Африке данных мало: ошибка там ~35–40% против ~20% для США.
- Есть подозрительные анкеты («полная занятость, $2 859 в год»), похоже на ошибки ввода в опросе.
