# Прогноз зарплаты в Data Science / ML

Регрессия годовой зарплаты (USD) по опыту, должности, стране, размеру компании и формату работы + Streamlit-приложение.

Данные: [Data Science Job Salaries](https://www.kaggle.com/datasets/ruchi798/data-science-job-salaries), 607 анкет за 2020–2022 (565 после удаления дублей).

## Результат

| Отложенный тест (20%) | |
|---|---|
| MAE | ≈ $29 000 |
| MedAE | ≈ $20 000 |
| R² (log) | 0,67 |
| Ошибка ≤ ±30% | 65% прогнозов |
| Бейзлайн (медиана), MAE | ≈ $53 000 |

Ridge, Random Forest и Gradient Boosting сравнивались на RepeatedKFold 5×3; разница между ними меньше разброса по фолдам. Выбрана Ridge на `log(salary_in_usd)`.

| Фактор (при прочих равных) | Эффект |
|---|---|
| Проживание в США против OTHER | ×3 |
| Страны с высоким уровнем зарплат против OTHER | ×2 |
| +1 уровень опыта | +27% |
| Лидерская роль | +32% |
| ML/AI против Analyst | +43% |
| +1 ступень размера компании | +12% |
| Доля удалёнки | ≈ 0 |

## Признаки

- `experience_level`, `company_size` → порядковые числа
- `job_title` (50 значений) → 5 семейств + флаг лидерской роли
- страны (59) → 4 региона по уровню зарплат + `same_country`
- `salary`, `salary_currency` удалены (утечка таргета)

Группировка даёт 20 признаков вместо 170 сырых one-hot колонок без потери качества.

## Структура

```

```

```bash
pip install -r requirements.txt
python src/train.py
streamlit run app.py
```

## Ограничения

Данные 2020–2022, больше половины — США; по регионам MID/OTHER ошибка ~35–40% против ~20% для США.
